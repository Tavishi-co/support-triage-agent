# Support Triage Agent 🤖

AI agent that triages support tickets across HackerRank, Claude, and Visa with **65.5% auto-resolution** and **0% hallucinations**.

## Architecture
- **Safety Checker** - Detects fraud/security risks
- **Product Classifier** - Routes to correct domain  
- **Document Retriever** - Hybrid similarity matching
- **Response Generator** - Grounded answers only

## Results
- ✅ 29 tickets processed in <2 seconds
- ✅ 65.5% auto-resolved | 34.5% escalated
- ✅ Zero hallucinations - all responses from corpus

## Tech Stack
`Python` `RAG Architecture` `NLP` `Pandas`
